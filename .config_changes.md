# Configuration Integration Summary

## Changes Made (Safe & Conservative)

### 1. Geometry Generation (`fclga_generate_geometry.py`)

**Before**: Hardcoded parameters
```python
MIN_LENGTH = 100.0
MAX_LENGTH = 200.0
MIN_HOLE_RADIUS = 10.0
MAX_HOLE_RADIUS = 20.0
RADIUS_TOLERANCE = 30.0
```

**After**: Loaded from `config/defaults.yaml`
```python
MIN_LENGTH = config['preprocessing']['geometry']['min_length']
MAX_LENGTH = config['preprocessing']['geometry']['max_length']
MIN_HOLE_RADIUS = config['preprocessing']['geometry']['min_hole_radius']
MAX_HOLE_RADIUS = config['preprocessing']['geometry']['max_hole_radius']
RADIUS_TOLERANCE = config['preprocessing']['geometry']['radius_tolerance']
```

**Benefit**: Edit `config/defaults.yaml` to change geometry ranges without touching code.

### 2. Parallel Simulations (`fclga_run_simulations.py`)

**Before**: Hardcoded
```python
NUM_PARALLEL_SIMULATIONS = 4
```

**After**: Loaded from config
```python
NUM_PARALLEL_SIMULATIONS = config['preprocessing']['simulation']['num_parallel_jobs']
```

**Benefit**: Adjust parallelism based on CPU cores in one place.

## What Was NOT Changed (Intentionally)

### Algorithm Parameters (Too Risky)

**`fclga_prepare_training_data.py`**:
- `tolerance_factor=0.05` - Hole edge detection threshold (5% of radius)
- `fixed_threshold=0.7` - Boundary condition detection criterion
- **Reason**: These affect feature engineering logic. Changing them changes the dataset.

**`fclga_extract_results.py`**:
- `field_name='E'` - Strain field name in Abaqus
- `component_index=0` - E11 component extraction
- **Reason**: These are FEA-specific parameters. Wrong values → wrong data.

**`fclga_generate_geometry.py`**:
- `MATERIAL_PROPERTIES` - Composite laminate properties (E1, E2, G12, etc.)
- `LAMINATE_LAYUP = [45, -45, -45, 45]` - Ply angles
- `PLY_THICKNESS = 0.25` - Physical ply thickness
- **Reason**: These are material physics. They define what you're simulating.

### Why This Conservative Approach?

1. **Data consistency**: Changing algorithm parameters invalidates existing datasets
2. **Physics integrity**: Material properties are domain knowledge, not hyperparameters
3. **User safety**: "Avoid breaking logic at any cost" → only move UI-level config

## Usage

To modify preprocessing behavior, edit `config/defaults.yaml`:

```yaml
preprocessing:
  geometry:
    min_length: 120     # Change from 100 to 120mm
    max_length: 250     # Change from 200 to 250mm
    min_hole_radius: 15 # Larger minimum hole
    
  simulation:
    num_parallel_jobs: 8  # Use more CPU cores
```

No code changes needed ✅

## Verification

Run preprocessing as normal:
```bash
conda run -n fclga python -m src.preprocessing.fclga_generate_geometry
conda run -n fclga python -m src.preprocessing.fclga_run_simulations
```

The scripts will automatically use values from `config/defaults.yaml`.
