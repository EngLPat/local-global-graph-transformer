# HybridAttentionGNN

This repository contains the code and data associated with the paper: **"Graph Neural Networks with Hybrid Local-Global Attention for Effective Prediction of Mechanical Response in Structures"**.

## Status

⏳ **Code and data will be made publicly available upon publication**

Upon acceptance and publication, this repository will include:
- Complete Graph Neural Network implementation
- Automated FEA-to-GNN pipeline
- Trained model weights
- Training dataset (500 samples)
- Testing and validation scripts
- Documentation and examples
